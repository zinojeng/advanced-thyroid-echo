# 病例模組的固定格式

CH12（高難度病例與影像陷阱）與各章 `kind: "case"` 的資源都採用同一套 11 步格式。
目的是讓學員**先自己判斷、再看答案**，而不是被動看完。

---

## 11 步

| # | 步驟 | 寫在哪個欄位 | 要求 |
|---|---|---|---|
| 1 | 臨床背景 | `target` 開頭 | 年齡、性別、TSH、症狀、相關病史。不要洩漏診斷 |
| 2 | 第一眼影像 | `dose` / `timestamps` | 指出資源中哪個時間點是「第一眼」 |
| 3 | 學員先作判斷 | `assessment` | **停下來寫下 structured description 與分級，再繼續** |
| 4 | 影像關鍵特徵 | `target` | 這個病例真正的判讀線索是什麼 |
| 5 | 鑑別診斷 | `target` | 至少三個，含最容易被選錯的那一個 |
| 6 | 風險分層 | `assessment` | 要求以 ACR TI-RADS 與至少一個其他系統分級 |
| 7 | 是否需要 FNA | `assessment` | 要有明確的 yes/no 與理由 |
| 8 | 下一步檢查 | `target` | FNA、追蹤、CT/MRI、核醫、轉介，擇一並說明 |
| 9 | 病理或追蹤結果 | `target` 結尾 | **沒有結局的病例要註明「無病理對照」** |
| 10 | 認知陷阱 | 單元的 `tight` | 這個病例最容易讓人栽在哪裡 |
| 11 | Take-home message | 單元的 `weak` | 一句話，可遷移到其他病例 |

---

## `assessment` 的寫法（先答再看）

單元的 `assessment` 欄位必須寫成可執行的「先答再看」指示，例如：

> 打開資源中 02:15 的靜止影像，先不看旁白，寫下你的 structured description
> （composition、echogenicity、shape、margin、echogenic foci）、ACR TI-RADS 分數與
> 是否穿刺的決定。再看完整段影片，記錄你和作者判斷不同的地方，
> 以及那個差異來自哪一個影像特徵。把差異寫進 logbook 的「判讀落差」欄。

不合格的寫法：

- ❌「了解橋本甲狀腺炎的影像特徵」——不是可執行的動作
- ❌「熟悉假性結節與真結節的差異」——沒有可驗收的產出
- ❌「觀看本單元影片」——把觀看當成完成標準

## `timestamps` 欄位

盡量為每個病例資源標出關鍵區間：

```json
"timestamps": [
  {"at": "02:15", "note": "第一眼影像——先在這裡暫停自己判斷"},
  {"at": "04:40", "note": "微鈣化與 comet-tail artifact 的對照"},
  {"at": "09:12", "note": "病理結果揭曉"}
]
```

`at` 用 `分:秒` 或 `時:分:秒`。**非影片資源（圖譜頁、期刊文章）省略此欄位**，
改在 `dose` 寫「看 Figure 2 與 Figure 3」這類指引。

---

## 沒有結局的病例

大量公開病例資源沒有病理或長期追蹤結果。這類資源**可以收**，但必須：

1. 在 `target` 結尾寫「無病理對照」
2. `tier` 最高只能給 `B`
3. 不得用來當作某個影像特徵的診斷證據

理由：沒有結局的病例可以練習**描述與分層**，但教不了**判讀正確性**。
把兩者混為一談，正是這門課要避免的錯誤。
