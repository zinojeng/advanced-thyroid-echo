# 結構化報告 Checklist（三種模板）

**Advanced Thyroid and Neck Ultrasonography — Structured Reporting Checklist**
對應單元：`ch13-u1`（結構化報告與最小影像集）、`ch7-u4`（術前報告模板與外科溝通）、`ch8-u1`～`ch8-u3`
對應能力：**C1, E2, X3**（次要：A1, A9, C5–C8, E4, E6, X1）

---

## 一、這份 checklist 要解決的問題

一份報告的品質，判準只有一個：

> **另一位醫師在不重新掃描的情況下，能否重現你的判讀，
> 並在下一次追蹤時做出有意義的比較？**

不能重現的報告，即使結論正確，也無法被檢驗、無法被比較、無法在
discrepancy review 中被檢討。因此本文件對每個欄位問的都是同一件事：
**少了它，下一位醫師會不會被迫重掃？**

### 三種模板

| 模板 | 使用時機 | 主要讀者 |
|---|---|---|
| **模板 A：甲狀腺結節報告** | 一般結節評估與追蹤 | 內分泌科、家醫科、病人 |
| **模板 B：頸部淋巴結報告（含術前 mapping）** | 已知或疑似甲狀腺惡性腫瘤的頸部評估 | **外科**（術前計畫） |
| **模板 C：術後追蹤報告** | 甲狀腺切除後的甲狀腺床與頸部追蹤 | 內分泌科、核醫、外科 |

三種模板共用一組**基本資料欄位**，差別在於病灶描述段與結論段。

### 欄位標示

| 標示 | 意義 |
|---|---|
| **【必填】** | 缺少此欄位，報告無法被重現或無法支撐結論 |
| 【條件必填】 | 在指定情境下為必填 |
| 【選填】 | 有助於品質但非必要 |

# 二、共用基本資料段（三種模板皆適用）

| # | 欄位 | 標示 | 說明 |
|---|---|---|---|
| 0-1 | 檢查日期與時間 | **【必填】** | |
| 0-2 | 檢查適應症／臨床問題 | **【必填】** | 寫「本次檢查要回答什麼」，不是「甲狀腺超音波」 |
| 0-3 | 相關臨床資訊 | **【必填】** | 甲狀腺功能、相關抗體、既往細胞學或病理、手術與治療史、家族史、輻射暴露史、目前與甲狀腺相關的用藥 |
| 0-4 | 比較影像 | **【必填】** | 明確寫出「與 YYYY-MM-DD 之影像比較」或「無先前影像可供比較」——**不可留空** |
| 0-5 | 檢查者 | **【必填】** | |
| 0-6 | 使用探頭與主要設定 | 【選填】 | 對追蹤比較與 Doppler 判讀有幫助（見 `ch1-u4`） |
| 0-7 | ★ **本次檢查未能評估的範圍與原因** | **【必填】** | 若無限制則明寫「無」。**留空等同於宣稱全部都看過了** |

> **0-7 是本 checklist 中最常被略過、也最容易造成臨床傷害的欄位。**
> 中央區被氣管遮蔽、胸骨後延伸下緣未及、病人無法擺位——
> 這些都必須寫出來。**報告沒寫，臨床會讀成「那裡沒有」。**

# 三、模板 A：甲狀腺結節報告

## A-1　腺體整體評估

| # | 欄位 | 標示 | 說明 |
|---|---|---|---|
| A1-1 | 兩葉與峽部的大小（三軸或前後徑） | **【必填】** | |
| A1-2 | 實質回音與均質性 | **【必填】** | **與帶狀肌／下頜下腺比較**；不可只寫「正常」 |
| A1-3 | 是否有瀰漫性病變的表現 | **【必填】** | 回音降低、粗糙不均、纖維化分隔、體積變化 |
| A1-4 | 整體血流狀況 | 【條件必填】 | 疑似 Graves 或破壞性甲狀腺炎時必填；**須註明 Doppler 設定**，否則不具跨檢查比較價值 |
| A1-5 | 錐狀葉是否可見 | 【選填】 | 術前評估時建議填寫 |
| A1-6 | 氣管位置（居中／偏移方向） | 【條件必填】 | 有大結節或甲狀腺腫時必填 |

## A-2　每一顆須報告結節的描述

> **哪些結節要逐一描述？**
> 依 `ch10-u3`：**最可疑的結節**（依影像特徵挑選，不是依大小）＋最大的幾顆。
> 多結節情境中，其餘以整體描述帶過，但須註明其型態與大小範圍。
> **挑最可疑的，不是挑最大的**——這是多結節性甲狀腺腫最常見的處置錯誤來源。

每一顆須報告的結節，以下欄位**全數必填**：

| # | 欄位 | 標示 | 說明 |
|---|---|---|---|
| A2-1 | **定位** | **【必填】** | 左／右／峽部；上／中／下段；前／後、內／外側。需精確到下次能找到同一顆 |
| A2-2 | **三軸大小** | **【必填】** | 含**橫切面上的前後徑與左右徑**，以及縱切面上的上下徑 |
| A2-3 | **Composition（成分）** | **【必填】** | 實質／幾乎全實質／混合囊實性／幾乎全囊性／海綿樣（spongiform） |
| A2-4 | **Echogenicity（回音）** | **【必填】** | 高／等／低／明顯低回音。**明顯低回音的判定基準為帶狀肌** |
| A2-5 | **Shape（形狀）** | **【必填】** | **在橫切面上**比較前後徑與左右徑，明確寫出是否成立 taller-than-wide |
| A2-6 | **Margin（邊緣）** | **【必填】** | 光滑／界線不清（ill-defined）／不規則或微分葉／甲狀腺外侵犯。**ill-defined 與 irregular 不可互換** |
| A2-7 | **Echogenic foci（強回音灶）** | **【必填】** | 無／comet-tail artifact／macrocalcification／rim（周邊）calcification／punctate echogenic foci。**可並存者須全數列出** |
| A2-8 | 部分囊性結節：**實質成分的獨立描述** | 【條件必填】 | 偏心實質成分的位置、回音、邊緣、echogenic foci。**風險由實質成分決定** |
| A2-9 | 與被膜的關係 | **【必填】** | 距離／接觸／被膜線是否中斷／輪廓是否突出 |
| A2-10 | 甲狀腺外侵犯（ETE）評估 | 【條件必填】 | 有接觸或輪廓變形時必填；須說明**接觸不等於侵犯**，並註明超音波對輕微 ETE 的判定能力有限 |
| A2-11 | 血流所見 | 【選填】 | 可記錄，但**須註明其非現行主要分層系統的計分項目** |
| A2-12 | 與先前影像的比較 | 【條件必填】 | 有先前影像時必填：**在同一平面上**比較，並說明是否為有意義的變化 |
| A2-13 | **風險分層結果** | **【必填】** | 所用系統的**名稱與版本** + 該結節的分級 |
| A2-14 | rim calcification 造成內部無法評估時的說明 | 【條件必填】 | 須另述鈣化環是否中斷、環外是否有低回音組織向外突出 |

# 五、模板 C：術後追蹤報告

> 這份報告的核心方法學是**縱向比對**。
> 單張影像的形態描述在術後族群的鑑別力有限；**變化的軌跡**才是判讀依據。

# 七、常見缺失清單

依 `ch13-u2`（判讀者間變異與 discrepancy review）整理。以下每一項都會讓
下一位醫師被迫重掃：

| # | 缺失 | 後果 |
|---|---|---|
| 1 | **未寫出未能評估的範圍** | 臨床把「沒寫」讀成「沒有」。中央區被氣管遮蔽是最常見的實例 |
| 2 | **只寫「TI-RADS 4」不寫系統與版本** | 無法重現分層，也無法知道採用的是哪一套價值取捨 |
| 3 | **shape 未標示判定平面** | 無法檢驗是否誤用縱切或斜切（斜切的偏誤方向是過度分級） |
| 4 | **comet-tail 與 punctate echogenic foci 混寫成「微鈣化」** | 良性膠質結節被推上高風險類別，導致不必要的穿刺 |
| 5 | **spongiform 標籤濫用** | 實質結節被寫成 spongiform，系統性低估風險 |
| 6 | **部分囊性結節只描述整體，未單獨描述實質成分** | 風險由實質成分決定，整體描述會稀釋掉可疑所見 |
| 7 | **定位不足以找到同一顆**（只寫「右葉結節」） | 追蹤時無法確定比較的是不是同一顆 |
| 8 | **測量無游標在位影像** | 下次追蹤無法在同一平面重測，2 mm 的誤差被讀成生長 |
| 9 | **結論只寫「建議追蹤」** | 沒有時間點、沒有內容、沒有觸發條件——這是延期，不是計畫 |
| 10 | **淋巴結只寫 level 不寫位置關係** | 外科在術中找不到你說的那一顆 |
| 11 | **對側葉未評估或未描述** | 外科無法決定手術範圍 |
| 12 | **術後報告只與上一次比較** | 漏掉跨年度的緩慢變化軌跡 |
| 13 | **無法被檢驗的斷言**（「型態高度懷疑惡性」而無描述支撐） | 無法被 discrepancy review 檢討 |
| 14 | **越權建議**（在無細胞學下直接建議手術） | 跳過診斷路徑 |
| 15 | **把血流寫成分層依據** | 血流非現行主要系統的計分項目 |
| 16 | **Doppler 所見未註明設定** | 跨檢查、跨醫師無可比較性 |

# 九、限制與聲明

1. 本 checklist 是**課程設計用的教學與品質工具**，不是任何學會、主管機關或
   醫院的正式報告規範。欄位的取捨與必填標示均為本課程的建議。
2. **實際的報告格式、必填欄位與保存規定，一律以所屬機構的規範
   與當地主管機關的要求為準。** 任何衝突之處以當地規範為準。
3. 本文件**不提供任何風險分層系統的具體分數、尺寸門檻或惡性率數字**。
   凡涉及分層，一律依所用系統原始文件的表格操作，
   並在報告中寫明系統名稱與版本。
4. 「最小影像集」的內容是本課程的建議下限，
   實際的影像保存要求依所屬機構的規範與儲存政策。
5. 稽核表的通過標準與關鍵項目設定為本課程建議，非任何外部標準。
   不同機構可依需求調整，但建議保留關鍵項目的設計邏輯：
   **某些欄位缺失無法被其他欄位的完整度補償。**
