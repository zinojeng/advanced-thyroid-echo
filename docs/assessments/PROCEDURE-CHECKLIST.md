## 一、如何使用本文件

### 三種用法

| 用法 | 對象 | 做法 |
|---|---|---|
| **操作前自我檢核** | 受訓者本人 | 每次操作前逐項確認，尤其是「術前」段 |
| **DOPS 評分** | 督導者 | 直接觀察一次完整操作，依評分尺度逐項評分 |
| **累積能力證據** | 受訓者 + 督導者 | 每次 DOPS 存檔，連同 `FELLOW-LOGBOOK.md` 構成 E9–E13 的證據 |

### DOPS 評分尺度

| 分數 | 意義 |
|---:|---|
| **0** | 未執行，或執行方式有安全疑慮 |
| **1** | 需要督導者提示或介入才能完成 |
| **2** | 獨立正確完成 |
| **3** | 獨立完成，且能向他人說明為什麼這樣做（達 Teach 層次） |
| **N/A** | 本次情境不適用（須註明原因） |

**★ 關鍵項目**：標示 ★ 的項目**必須達到 2 分以上**。
任一關鍵項目得 0 或 1 分，本次 DOPS 判定為**未通過**，
不論總分為何，且該次操作應由督導者接手或全程直接指導。

### 判定

| 項目 | 標準 |
|---|---|
| 總分 | 各適用項目的得分 ÷（適用項目數 × 3）× 100% |
| **通過** | 總分 ≥ 70% **且**所有 ★ 關鍵項目 ≥ 2 分 |
| **獨立操作建議門檻** | 連續 3 次 DOPS 通過，且無關鍵項目失分——**但最終仍依當地 credentialing 規範** |

# 二、術前（Pre-procedure）

## A. 適應症與決策

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| A1 | ★ 確認**這顆結節符合穿刺適應症**：說得出所依據的分層系統名稱與版本、該結節的分級、以及該系統對此分級與尺寸的建議 | ☐ | 「臨床醫師要求」不是適應症 |
| A2 | ★ 確認**穿刺目標是正確的病灶**：在多結節情境中，說明為什麼穿這一顆而不是最大的那一顆 | ☐ | 挑最可疑的，不是挑最大的 |
| A3 | 對部分囊性結節，明確指出**取樣目標是偏心的實質成分**而非囊液 | ☐ | |
| A4 | 說明本次操作**要回答什麼臨床問題**，以及結果會如何改變處置 | ☐ | 結果不改變處置的檢查，適應症本身就有疑問 |
| A5 | 檢視是否有**先前的 FNA 結果**；若為重複穿刺，說明本次要改變什麼（取樣位置、次數、輔助評估） | ☐ | 同樣方法做第三次沒有理由得到不同結果 |
| A6 | 若病灶同時需要淋巴結取樣，說明取樣順序與各自的檢體處理計畫 | ☐ | |

## B. 病人評估與準備

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| B1 | ★ **確認病人身分與穿刺部位（左／右、哪一顆）**，並依機構規範完成 time-out／部位標記 | ☐ | 左右側錯誤是可預防的重大事件 |
| B2 | ★ 詢問並記錄**抗凝血劑／抗血小板藥物**使用情形，以及出血病史 | ☐ | |
| B3 | ★ 若使用抗凝血劑：說明處理計畫是**個別化評估、與處方醫師／相關專科共同決定**，而非反射性停藥 | ☐ | 停藥的血栓風險可能高於出血風險 |
| B4 | 詢問過敏史（含局部麻醉劑、消毒劑、乳膠） | ☐ | |
| B5 | 評估病人是否能配合姿勢與閉氣；有頸部活動限制者，預先規劃替代姿勢 | ☐ | |
| B6 | 詢問先前類似操作的不良反應（尤其是**迷走反應**病史） | ☐ | 有病史者應預先平躺並備妥處置 |

## C. 知情同意

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| C1 | ★ 說明**操作目的**與預期得到的資訊 | ☐ | 只講風險不講目的是常見缺失 |
| C2 | ★ 主動說明 **nondiagnostic 的可能性**及其後續處理（可能需重做或改用其他取樣方式） | ☐ | 這是最常發生的「結果」，事前不說會損害信任 |
| C3 | 說明常見不適與併發症：疼痛、瘀血、局部血腫、迷走反應 | ☐ | |
| C4 | 說明罕見但嚴重的併發症：擴大血腫與氣道壓迫、感染 | ☐ | |
| C5 | ★ 說明**不做的替代方案與其風險**（影像追蹤及其不確定性） | ☐ | |
| C6 | 說明檢體送檢流程與**大約何時、以何種方式得知結果** | ☐ | |
| C7 | 確認病人理解（請病人複述重點或主動邀請提問），並依機構規範完成書面同意 | ☐ | |
| C8 | 語言可被非醫療人員理解，未使用未經轉譯的術語 | ☐ | |

## D. 設備、環境與無菌準備

> 本段所有項目的**具體做法一律依所屬機構的感染管制規範**。
> 以下僅為提醒清單，不構成規範內容。

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| D1 | 確認超音波機器設定：探頭選擇、preset、depth、focus 位於目標深度 | ☐ | |
| D2 | 確認可用的**針具規格與數量**（含備用針）、注射器、玻片或液基保存液、標籤 | ☐ | |
| D3 | ★ 依機構規範完成**手部衛生、皮膚消毒與探頭處理**（探頭套／消毒方式依規範） | ☐ | |
| D4 | 準備無菌耦合劑或依規範使用的替代方式 | ☐ | |
| D5 | ★ 若需 washout：**預先備妥沖洗用生理食鹽水與獨立的檢體容器**，並確認實驗室的送檢要求 | ☐ | 事後才想到就來不及了 |
| D6 | 備妥壓迫用敷料、急救設備位置已確認、有可協助的人員在場或可即時呼叫 | ☐ | |
| D7 | 確認銳器盒位置與處置方式 | ☐ | |

## E. 擺位與掃描規劃

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| E1 | 病人**平躺**，肩下墊枕使頸部適度延展；無法配合者採用可耐受的替代姿勢並記錄 | ☐ | 平躺可降低迷走反應後跌倒的風險 |
| E2 | ★ **重新掃描確認目標病灶**，並在螢幕上確定其與周邊構造（頸動脈、頸靜脈、氣管、食道、神經走行區）的關係 | ☐ | 不可依賴先前的報告直接下針 |
| E3 | ★ **規劃進針路徑**並說明選擇理由（避開血管、選擇針身可全程可視的角度、必要時採 trans-isthmic 路徑） | ☐ | |
| E4 | 對深部或被鈣化遮蔽的病灶：說明替代路徑或角度調整方案 | ☐ | |
| E5 | 確認操作者、機器螢幕與病人的相對位置，使操作時不需轉頭離開螢幕 | ☐ | |

# 三、術中（Intra-procedure）

## F. 麻醉與進針

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| F1 | 依機構規程處理局部麻醉（是否使用、藥物與劑量），並向病人說明接下來的感受 | ☐ | |
| F2 | ★ 採 **in-plane（parallel）**路徑，使**針身全長落在聲束平面內** | ☐ | Out-of-plane 只看得到一個亮點，無法確知是針尖 |
| F3 | ★ **針尖在推進的每一刻都可視**；看不到針尖時**停止推進**，先調整角度或探頭位置 | ☐ | 這是本 checklist 最重要的單一項目 |
| F4 | 針顯示不清時，先嘗試調整入射角度、探頭位置或使用機器的針顯影功能，而非盲目推進或單純提高 gain | ☐ | |
| F5 | 進針過程中持續注意與頸動脈、頸靜脈的距離 | ☐ | |
| F6 | 與病人保持溝通（提醒不要吞嚥、不要說話、必要時短暫閉氣） | ☐ | |

## G. 取樣

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| G1 | ★ **確認針尖位於目標病灶內**（而非周邊正常組織或鄰近結節）後才開始取樣 | ☐ | |
| G2 | 使用適當的取樣手法（毛細管法或抽吸法），並依組織回饋調整 | ☐ | |
| G3 | 在病灶內做小幅度的來回移動以增加取樣量，同時維持針尖可視 | ☐ | |
| G4 | 對**部分囊性**病灶：取樣目標為偏心實質成分；若先抽液造成塌陷，說明如何維持定位 | ☐ | 囊液是 nondiagnostic 的主因 |
| G5 | 對**含鈣化**病灶：避開鈣化與其聲影，說明繞行策略 | ☐ | |
| G6 | 對**深部或微小**病灶：說明角度、路徑或姿勢的調整；若無法安全可視，**記錄無法安全取樣的事實**並與臨床討論 | ☐ | 放棄取樣可以，但不能因此判定為良性 |
| G7 | 觀察抽出物性狀（血性、囊液、膠質、組織）並即時判斷是否需調整策略 | ☐ | |
| G8 | 執行足夠的取樣次數；若可行，使用現場適足性評估（ROSE）決定是否需追加 | ☐ | ROSE 是否可用依機構資源 |
| G9 | 每次取針後立即檢視穿刺點並施予壓迫 | ☐ | |

## H. 淋巴結取樣與 washout

*僅在本次操作包含淋巴結取樣時適用。*

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| H1 | ★ 說明該淋巴結**為什麼值得穿刺**：具有較高特異度的徵象，且結果會改變處置 | ☐ | fatty hilum 消失單獨不足以構成適應症 |
| H2 | 精確記錄該淋巴結的 **level 與其相對於頸動脈／頸內靜脈／鎖骨／胸鎖乳突肌的位置** | ☐ | 讓外科在術中找得到同一顆 |
| H3 | ★ **先完成細胞學取樣**，再進行 washout | ☐ | |
| H4 | ★ Washout 的檢體處理：以少量生理食鹽水沖洗針具，沖洗液**單獨裝入獨立容器送檢**；細胞學與 washout 為**兩份分開的檢體** | ☐ | 處理錯誤會讓整個檢查失去意義 |
| H5 | 說明本例選擇 **Tg washout 還是 PTH washout** 的理由 | ☐ | Tg 用於甲狀腺癌轉移，PTH 用於副甲狀腺定位 |
| H6 | 說明本例 washout 判讀的**限制**（例如甲狀腺完整者的 Tg washout、TgAb 陽性者的干擾、PTH washout 的污染與取樣偏差） | ☐ | |

## I. 檢體處理與標示

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| I1 | ★ **檢體標示正確**：病人身分、部位（左／右、腺葉位置或淋巴結 level）、檢體類型 | ☐ | 多部位取樣時標錯是重大事件 |
| I2 | 依實驗室要求處理檢體（塗片固定方式、液基保存液、送檢時限） | ☐ | 依機構與實驗室規定 |
| I3 | ★ 申請單上提供**臨床資訊與具體的臨床疑問**（例如「懷疑髓質癌，請考慮相關染色」「術後追蹤，懷疑復發」「病人有他處原發癌病史」） | ☐ | 病理醫師不知道你在想什麼，就無法幫你 |
| I4 | 多部位取樣時，各檢體分開標示且送檢單上可對應 | ☐ | |

# 四、術後（Post-procedure）

## J. 立即處置與觀察

| # | 項目 | 分數 | 備註 |
|---|---|:---:|---|
| J1 | ★ 穿刺後**直接壓迫**穿刺部位足夠時間；使用抗凝血劑者延長壓迫 | ☐ | |
| J2 | 覆蓋敷料，並**重新掃描穿刺區域**確認無明顯出血或血腫形成 | ☐ | |
| J3 | ★ 病人**於院內觀察一段時間**再離開（時間依機構規範與病人風險） | ☐ | 立即離開的病人，血腫發生時不在你的視線內 |
| J4 | 觀察期間確認病人可正常說話、吞嚥、呼吸 | ☐ | |
| J5 | 起身前先坐起片刻，確認無頭暈再站立 | ☐ | 迷走反應後跌倒是可預防的傷害 |

| # | 項目 | 分數 | 備註 |

| K3 | 提供**可聯絡的管道**（白天與夜間分別怎麼辦） | ☐ | |
| K4 | 說明取得結果的時間與方式，以及回診安排 | ☐ | |
| K5 | 確認病人有人陪同或可安全返家（尤其發生過迷走反應者） | ☐ | |

# 五、併發症辨識與處置

> 本段是**辨識與初步處置的提醒**，不是完整的臨床處置規範。
> 實際處置一律依所屬機構的規程與可用資源。

## M. 迷走神經反應（vasovagal reaction）

| 辨識 | 處置 |
|---|---|
| **心跳變慢**、臉色蒼白、冒冷汗、頭暈、噁心、可能短暫意識不清 | 立即停止操作、平躺並抬高下肢、鬆開頸部束縛、監測生命徵象、持續觀察至完全恢復；恢復後緩慢起身 |
| **關鍵鑑別**：**頸部無腫脹**，心跳**變慢** | 與血腫的方向相反（見下） |

| # | 評分項目 | 分數 |
|---|---|:---:|
| M1 | ★ 正確辨識迷走反應（能說出心跳變慢是關鍵鑑別點） | ☐ |
| M2 | 處置順序正確：停止操作 → 平躺抬腿 → 監測 → 觀察至恢復 | ☐ |
| M3 | 說明有此病史者，下次操作前的預防措施 | ☐ |

## N. 血腫（hematoma）

| 辨識 | 處置 |
|---|---|
| 頸部腫脹、緊繃、疼痛、**心跳加快**；若壓迫氣道則出現呼吸費力、聲音改變、喘鳴 | **呼吸道評估與監測優先**；同時直接壓迫；給氧；立即通報並準備緊急氣道處置資源；超音波可同步確認範圍與是否持續擴大，**但不得延誤氣道評估** |
| **關鍵鑑別**：頸部**腫脹緊繃**，心跳**加快** | 甲狀腺區位於封閉筋膜間隙，血腫可在短時間內壓迫氣道 |

| # | 評分項目 | 分數 |
|---|---|:---:|
| N1 | ★ 正確辨識擴大中的血腫（能說出心跳加快 + 頸部腫脹是關鍵組合） | ☐ |
